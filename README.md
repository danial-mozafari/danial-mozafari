# قیمت دلار لحظه‌ای (USD Price Widget)

پروژه‌ی آموزشی: یک ویجت شناور دسکتاپ + یک PWA موبایل که قیمت دلار رو
لحظه‌ای نشون می‌ده. بک‌اند با Python (Flask)، فرانت با HTML/CSS/JS ساده،
پنجره‌ی دسکتاپ با `pywebview`.

## ویژگی‌ها

- قیمت لحظه‌ای دلار با انیمیشن نرم و رنگ‌بندی سبز/قرمز
- درصد تغییر لحظه‌ای
- نمودار روند اخیر
- باکس «باز شدن امروز / بسته‌شدن دیروز / بیشترین و کمترین امروز»
  (این‌ها به‌مرور که برنامه رو باز نگه داری پر و دقیق‌تر میشن)
- هشدار قیمتی: چند آستانه تعریف کن (مثلاً «≥ ۷۰,۰۰۰»)؛ وقتی قیمت بهش
  برسه یک پیام شناور (Toast) بزرگ بالای صفحه + صدای بیپ + لرزش گوشی
  (روی اندروید) می‌بینی. این روش عمداً جایگزین Notification سیستم‌عاملی
  شده چون iOS (سافاری و کروم iOS) اصلاً از Notification ساده‌ی جاوااسکریپتی
  پشتیبانی نمی‌کنه — فقط با Web Push (که سرور جدا می‌خواد) کار می‌کنه.
  Toast روی هر گوشی/مرورگری، بدون هیچ اجازه‌ای، کار می‌کنه.
- حالت تیره/روشن (دکمه‌ی 🌙/☀️ بالای صفحه)
- یک صفحه‌ی واحد و یکپارچه — هم دسکتاپ، هم موبایل، هم PWA

## نصب

```bash
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## اجرا

**۱. سرور رو بالا بیار (همیشه باید در حال اجرا باشه):**
```bash
python app.py
```
یه پیام می‌بینی که سرور روی `http://0.0.0.0:5000` بالا اومده.

**۲. توی مرورگر تست کن:**
باز کن `http://127.0.0.1:5000` — باید ببینی هر ۳ ثانیه قیمت (شبیه‌سازی‌شده)
عوض می‌شه.

**۳. ویجت دسکتاپ (پنجره‌ی شناور):**
در یک ترمینال جدا (بدون بستن ترمینال قبلی):
```bash
python desktop_widget.py
```
یک پنجره‌ی کوچیک، بدون کادر، همیشه-روی-بقیه باز میشه که فقط قیمت رو نشون
می‌ده و با موس هم قابل جابجاست.

**۴. روی گوشی (بدون هیچ اپ‌استوری):**
گوشی و کامپیوتر باید توی یک وای‌فای باشن. آی‌پی کامپیوترت رو پیدا کن:
- ویندوز: `ipconfig` → دنبال IPv4 Address بگرد
- مک/لینوکس: `ifconfig` یا `ip addr`

توی مرورگر گوشی برو به `http://<IP-کامپیوتر>:5000` (مثلاً `http://192.168.1.5:5000`)
و از منوی مرورگر «Add to Home Screen» رو بزن. حالا یه آیکون رو صفحه اصلی
گوشیت داری؛ با زدنش، مستقیم همون داشبورد کامل باز میشه (بدون نوار آدرس
مرورگر) — دقیقاً همون چیزی که روی دسکتاپ می‌بینی.

> **نکته‌ی مهم:** این با ویجت واقعی صفحه‌ی اصلی اندروید (که بدون باز کردن
> اپ، قیمت رو نشون میده) فرق داره. سیستم‌عامل موبایل (اندروید/iOS) اجازه
> نمی‌ده یه وب‌اپ پنجره‌ی شناور روی بقیه‌ی اپ‌ها داشته باشه — این قابلیت
> فقط با برنامه‌نویسی نیتیو (Kotlin/Swift) ممکنه، که پروژه‌ی جدا و
> بزرگ‌تریه. چیزی که ساختیم نزدیک‌ترین معادلشه: یه تپ تا دیدن همه‌چیز.

> برای اینکه از بیرون خونه هم (نه فقط توی همون وای‌فای) در دسترس باشه،
> باید `app.py` رو روی یک هاست رایگان مثل Render، Railway یا PythonAnywhere
> دیپلوی کنی — این قدم بعدی طبیعیه بعد از اینکه لوکال جواب داد.

## قیمت واقعی (BrsApi.ir) — از قبل وصل شده

کد الان به BrsApi.ir وصله. فقط کافیه کلیدی که از سایت گرفتی رو به‌عنوان
متغیر محیطی ست کنی — **هیچ‌وقت مستقیم توی کد ننویسش**، چون این پروژه قراره
بره گیت‌هاب و هرکسی می‌تونه کلیدت رو ببینه و از اعتبار رایگانت استفاده کنه.

**مک/لینوکس:**
```bash
export BRSAPI_KEY="کلید_خودت"
USE_REAL_API=1 python app.py
```

**ویندوز (PowerShell):**
```powershell
$env:BRSAPI_KEY="کلید_خودت"
$env:USE_REAL_API="1"
python app.py
```

با `USE_REAL_API=1` فاصله‌ی آپدیت خودکار میره روی ۶۰ ثانیه (به‌جای ۳ ثانیه‌ی
حالت شبیه‌ساز) تا از سقف رایگان ۱۵۰۰ درخواست در روز رد نشیم و IP بلاک نشه.
اگه دیدی جواب API رو درست پارس نمی‌کنه (پیام خطای «آیتم دلار پیدا نشد»)،
خط `# print("RAW RESPONSE:", data)` توی `fetch_real_price()` رو از حالت
کامنت خارج کن تا ساختار دقیق جواب رو ببینی و پارس کردنش رو تنظیم کنی.

> بدون `USE_REAL_API=1`، برنامه همچنان با شبیه‌ساز (نوسان تصادفی) کار
> می‌کنه — خوبه برای توسعه‌ی رابط کاربری بدون مصرف سهمیه‌ی API.

## نوتیفیکیشن واقعی روی گوشی (Web Push)

هشدار قیمتی الان یک نوتیفیکیشن **واقعی سیستم‌عامل** می‌فرسته (نه فقط پیام
داخل صفحه) — با تکنولوژی استاندارد Web Push. اولین بار که `python app.py`
رو اجرا کنی، یک جفت کلید امنیتی (VAPID) خودکار ساخته و توی
`vapid_private_key.pem` ذخیره میشه — این فایل رو هیچ‌وقت به گیت‌هاب پوش نکن
(توی `.gitignore` هست).

### ⚠️ محدودیت مهم: فقط روی HTTPS کار می‌کنه

مرورگرها (به‌خصوص iOS) اجازه‌ی Web Push روی آدرس‌های `http://` عادی
(مثل `http://172.20.10.5:5000`) رو نمی‌دن. برای تست واقعی، دو راه داری:

**راه سریع برای تست (چند دقیقه‌ای، با ngrok):**
1. از https://ngrok.com یه حساب رایگان بساز و برنامه‌ش رو دانلود کن
2. با `python app.py` سرور رو بالا بیار (پورت ۵۰۰۰)
3. در یک ترمینال جدا:
   ```powershell
   ngrok http 5000
   ```
4. یه آدرس شبیه `https://xxxx-xx-xx.ngrok-free.app` بهت میده — همینو (نه IP لوکال) روی گوشیت باز کن
5. از همون‌جا «Add to Home Screen» بزن و هشدار تنظیم کن

> توجه: هر بار که ngrok رو ری‌استارت کنی، آدرس عوض میشه (نسخه‌ی رایگانش).
> برای آدرس ثابت باید یا حساب Pro بگیری یا بری سراغ دیپلوی واقعی.

**راه همیشگی (دیپلوی واقعی — پیشنهاد نهایی):**

با این کار، برنامه ۲۴ ساعته روی اینترنت بالاست، بدون نیاز به روشن بودن
کامپیوترت یا باز بودن پاورشل. مراحل با **Render** (رایگان):

1. کد رو به گیت‌هاب پوش کن (پایین توضیح داده شده)
2. برو به https://render.com و با گیت‌هابت وارد شو (ثبت‌نام رایگان)
3. **New +** → **Web Service** → ریپوی همین پروژه رو انتخاب کن
4. تنظیمات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --workers 1 --bind 0.0.0.0:$PORT`
     (این از قبل توی فایل `Procfile` هم هست، Render خودش پیدا می‌کنه)
5. توی بخش **Environment**، این متغیرها رو اضافه کن:
   - `USE_REAL_API` = `1`
   - `BRSAPI_KEY` = کلید خودت
   - `VAPID_PRIVATE_KEY_PEM` = (بعد از اولین اجرا در ادامه توضیح میدم چطور بگیریش)
6. **Create Web Service** بزن و صبر کن دیپلوی تموم بشه (چند دقیقه)
7. یه آدرس دائمی شبیه `https://usd-price-widget.onrender.com` بهت میده

**گرفتن VAPID_PRIVATE_KEY_PEM (فقط یک‌بار لازمه):**
بعد از اولین دیپلوی (بدون این متغیر)، برو به تب **Logs** توی داشبورد Render.
یه پیام می‌بینی که کلید خصوصی رو چاپ کرده (چون کد همینو بهت نشون میده).
اون متن رو کپی کن، به‌عنوان مقدار `VAPID_PRIVATE_KEY_PEM` توی Environment
اضافه کن و سرویس رو **Manual Deploy → Redeploy** کن. این کار باعث میشه
حتی اگه Render سرویس رو ری‌استارت کنه، کلید عوض نشه و گوشی‌های مشترک‌شده
همچنان معتبر بمونن.

> **نکته‌ی مهم درباره‌ی پلن رایگان Render:** اگه ۱۵ دقیقه هیچ‌کس به سایت
> سر نزنه، سرویس می‌خوابه و دفعه‌ی بعد چند ثانیه طول می‌کشه بیدار بشه —
> و تا وقتی خوابه، حلقه‌ی پس‌زمینه (که هشدارها رو چک می‌کنه) هم متوقفه.
> برای بیدار نگه‌داشتنش، می‌تونی از یه سرویس رایگان مثل
> https://cron-job.org هر ۱۰ دقیقه یه‌بار به آدرست درخواست بفرسته. اگه
> واقعاً بدون هیچ وقفه‌ای (حتی چند ثانیه) بخوایش، پلن پولی Render
> (حدود ۷ دلار در ماه) بدون خواب رفتن اجرا میشه.

### چطور مطمئن بشم که کار می‌کنه؟

بعد از اضافه کردن هشدار، توی Console مرورگر (F12 → Console) نباید خطایی
ببینی. اگه دیدی، متن خطا رو برام بفرست. همچنین می‌تونی روی دسکتاپ (که
`localhost` هست و محدودیت HTTPS نداره) اول تست کنی تا مطمئن بشی زیرساخت
سرور درسته، بعد بری سراغ گوشی با ngrok یا Render.

## قدم‌های بعدی برای گسترش (به ترتیب پیشنهادی)

1. **قیمت واقعی** — از قبل وصل شده؛ بالا توضیح داده شد.
2. **WebSocket به‌جای polling** — با `Flask-SocketIO`، سرور خودش قیمت رو
   push می‌کنه به‌جای اینکه کلاینت هر ۳ ثانیه بپرسه. تاخیر کمتر، ترافیک کمتر.
3. **اجرای خودکار ویجت هنگام روشن شدن ویندوز** — اسکریپت رو به Startup
   ویندوز اضافه کن.
4. **پکیج کردن به exe** — با `pyinstaller` ویجت رو به یک فایل اجرایی مستقل
   تبدیل کن که کاربر نیازی به نصب پایتون نداشته باشه.
5. **دیتابیس واقعی (sqlite3)** به‌جای فایل JSON برای تاریخچه — امکان
   نمودار هفتگی/ماهانه هم فراهم میشه.
6. **ویجت واقعی اندروید با KWGT** — بدون کدنویسی نیتیو، اپ KWGT رو نصب
   کن و به `/api/price` وصلش کن تا یه ویجت واقعی (بدون باز کردن اپ) رو
   صفحه‌ی اصلی گوشیت داشته باشی.
